Verification covers the twelve system requirements of KT-SRS-001 on the selected integration. The only case in the model is an analysis of that integration. It does not cover a built board, a firmware image or a molded enclosure, because none of those exist as evidence yet.

Validation covers the five customer requirements of KT-CRS-001. No validation case is in the model. The validation section states the activity that would accept or reject each need. This plan does not record a result for it.

Module budgets are not split out of the system requirements. There is no separate module verification matrix. A failure of the system analysis is read on the integration assert that failed, and from there on the subsystem attribute that assert uses.
